# PDP+ integration sample (unofficial)

Sample portal page for Climate Pulse (PopIntel Track 1). The track page asks that tools be integrated into PDP+ and country workflows (https://pdp.unfpa.org/popInthackathon/). This folder is an unofficial demo of that layout: a short method summary, Owner-only ArcGIS cards, and links to the package docs. It is not production PDP+ and is not hosted by UNFPA.

## Open locally

```text
pdp-plus-sample/index.html
```

Works via `file://` or any static host (GitHub Pages, nginx, etc.).

## Mapping to the official clause

| Official phrase | This sample |
|---|---|
| integrated into PDP+ | Sample page and links. Production embedding needs UNFPA platform access |
| country workflows | Cards for KEN (primary) and NGA / MEX / IND demos |
| Esri dashboard deployed | Owner-only URLs in section 4 of the page |
| Code open-sourced | This package (MIT), scripts, and docs |

## Assets

Local PNG previews under `assets/` are screenshots and map renders from the Climate Pulse build, for when the ArcGIS iframe is blank.
