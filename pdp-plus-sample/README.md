# PDP+ integration sample (unofficial)

## Purpose

Official PopIntel language asks that Track 1 tools be **“integrated into PDP+ and country workflows”**
(https://pdp.unfpa.org/popInthackathon/). This folder is a **self-contained sample portal page** that:

1. Explains Climate Pulse next to that official framing.
2. Deep-links / cards the team’s existing Owner-only ArcGIS Dashboards & Experience.
3. Points to the open-source method docs in this package.

## What this is not

- Not hosted by UNFPA
- Not the production Population Data Portal (`https://pdp.unfpa.org/`)
- Not a write into real PDP+ (that needs UNFPA platform access / country workflows)
- Not a claim that Country pilot is active

## Open locally

```text
# from this folder, or open the file in a browser:
pdp-plus-sample/index.html
```

Works via `file://` or any static host (GitHub Pages, nginx, etc.).

## Mapping to the official clause

| Official phrase | This sample |
|---|---|
| integrated into PDP+ | Simulated portal chrome + links; real embedding needs UNFPA |
| country workflows | Cards for KEN (primary) + NGA/MEX/IND demos |
| Esri dashboard deployed | Live Owner-only URLs wired in section 4 |
| Code open-sourced | Parent package MIT + scripts/docs |

## Assets

Local PNG previews under `assets/` are screenshots / map renders from the Climate Pulse build — for offline illustration when ArcGIS iframes are blocked.
